# `CATransform3D`: `m41` property

The **`m41`** property is the number in the fourth row, first column of the matrix. It is the translation in the x direction.

## Value

A number, in [pt](../units.md). Its position in the matrix:

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

When a point is transformed, it is added directly to the new x'. See [how the matrix acts on a point](../ca-transform-3d.md).

- Read-only. Assigning to it throws `TypeError: m41 is read-only: structs are values, assign a whole new one instead`.

## Examples

```js
const t = CATransform3D.translation(10, 20, 30);
console.log(t.m41);
```

**Result**: logs `10`.

## Corresponding iOS API

The C struct field `CATransform3D.m41`.
