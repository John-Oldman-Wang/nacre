# `CATransform3D`: `m24` property

The **`m24`** property is the number in the second row, fourth column of the matrix. It is used for perspective and is usually 0.

## Value

A number, in reciprocal pt (1/pt). Its position in the matrix:

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

When a point is transformed, the original y is multiplied by it and added to the new w'. At the end, x', y', and z' are all divided by w'. See [how the matrix acts on a point](../ca-transform-3d.md).

- Read-only. Assigning to it throws `TypeError: m24 is read-only: structs are values, assign a whole new one instead`.

## Examples

```js
const t = CATransform3D.identity;
console.log(t.m24);
```

**Result**: logs `0`.

## Corresponding iOS API

The C struct field `CATransform3D.m24`.
