# `CATransform3D`：`m24` 属性

**`m24`** 属性是矩阵第二行第四列的数。它是透视用的数，一般是 0。

## 值

数，单位是 pt 的倒数（1/pt）。在矩阵里的位置：

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

变换一个点时，原来的 y 乘以它，加进新的 w'。最后 x'、y'、z' 都除以 w'。见[矩阵怎么作用在点上](../ca-transform-3d.md)。

- 只读。给它赋值抛 `TypeError: m24 is read-only: structs are values, assign a whole new one instead`。

## 示例

```js
const t = CATransform3D.identity;
console.log(t.m24);
```

**结果**：输出 `0`。

## 对应的 iOS API

C 结构体的字段 `CATransform3D.m24`。
