# 单位

这一页说明 API 里的数值用什么单位。各参考页里每个数值属性都会标出单位，并链到这里。

## 长度和坐标：点

所有长度、坐标、尺寸、间距的单位都是**点**（point，Apple 文档里写作 pt）。包括 `frame`、`bounds`、`contentOffset`、`spacing`、`cornerRadius`、约束的 `constant`、字体大小。

点不是像素。一个点对应几个像素由屏幕决定：

| 屏幕 | 1 点等于 |
| --- | --- |
| @2x | 2 × 2 像素 |
| @3x（目前大多数 iPhone） | 3 × 3 像素 |

同一个点值在不同屏幕上的物理大小大致相同，所以写 `spacing = 6` 不用考虑设备。

> **注意**：JS 现在读不到屏幕是 @2x 还是 @3x，这项能力还没暴露。

### 点值会不会跟着缩放

写入的点值本身永远不会被系统改掉，读回来还是原来的数。会变的是它在屏幕上看起来多大：

| 情况 | 点值变不变 | 看起来变不变 |
| --- | --- | --- |
| 换到像素密度不同的屏幕 | 不变 | 不变。系统自动换算成像素 |
| 用户在系统设置里调大文字（动态字体） | 不变 | 不变。间距和尺寸不会跟着文字放大，要跟随得自己处理 |
| 用户开启「放大显示」 | 不变 | 变大。屏幕的总点数变少，所有内容等比放大 |
| 自己或祖先视图设了 `transform` 缩放 | 不变 | 跟着缩放。`transform` 作用在画面上，不改属性值 |

### 小数

点值可以是小数。要画一条 1 像素的细线，在 @3x 屏上是 `1 / 3` 点。

没有落在像素边界上的值可能让边缘发虚，比如 @3x 屏上的 `0.5` 点。

### 坐标方向

原点在左上角，`x` 向右增大，`y` 向下增大。

## 其他单位

| 量 | 单位 | 例子 |
| --- | --- | --- |
| 角度 | 弧度 | `CGAffineTransform` 的旋转、`UIBezierPath` 的圆弧 |
| 动画时长 | 秒 | `CABasicAnimation` 的 `duration` |
| 定时器延迟 | 毫秒 | `setTimeout()` 的第二个参数 |
| 不透明度 | 0 到 1 的比例 | `alpha`、`opacity` |
| 图层的单位坐标 | 0 到 1 的比例，相对图层自身大小 | `CAGradientLayer` 的 `startPoint` |
| 布局优先级 | 1 到 1000 的无单位数 | 约束的 `priority` |

> **注意**：动画时长是秒，定时器是毫秒，两者不一样。
