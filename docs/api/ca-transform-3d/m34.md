# `CATransform3D`：`m34` 属性

**`m34`** 属性是矩阵第三行第四列的数。它决定透视：设成 `-1 / d` 时，看的人到屏幕平面的距离是 `d` pt。单位矩阵里它是 0，没有透视。

## 值

数，单位是 pt 的倒数（1/pt）。在矩阵里的位置：

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

变换一个点时，原来的 z 乘以它，加进新的 w'。最后 x'、y'、z' 都除以 w'。见[矩阵怎么作用在点上](../ca-transform-3d.md)。

- 只读。给它赋值抛 `TypeError: m34 is read-only: structs are values, assign a whole new one instead`。

## 示例

```js
const t = { ...CATransform3D.identity, m34: -1 / 500 };
const layer = new CALayer();
layer.transform = t;
console.log(layer.transform.m34);
```

**结果**：输出 `-0.002`。

## 对应的 iOS API

C 结构体的字段 `CATransform3D.m34`。
