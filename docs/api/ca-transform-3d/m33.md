# `CATransform3D`：`m33` 属性

**`m33`** 属性是矩阵第三行第三列的数。只有缩放时它是 z 方向的倍数。

## 值

数，比例，没有单位。在矩阵里的位置：

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

变换一个点时，原来的 z 乘以它，加进新的 z'。见[矩阵怎么作用在点上](../ca-transform-3d.md)。

- 只读。给它赋值抛 `TypeError: m33 is read-only: structs are values, assign a whole new one instead`。

## 示例

```js
const t = CATransform3D.scale(2, 3, 4);
console.log(t.m33);
```

**结果**：输出 `4`。

## 对应的 iOS API

C 结构体的字段 `CATransform3D.m33`。
