# `CATransform3D`: `m32` property

The **`m32`** property is the number in the third row, second column of the matrix. When there is only a rotation around the x axis, it is the negated sine of the angle.

## Value

A number; a ratio with no unit. Its position in the matrix:

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

When a point is transformed, the original z is multiplied by it and added to the new y'. See [how the matrix acts on a point](../ca-transform-3d.md).

- Read-only. Assigning to it throws `TypeError: m32 is read-only: structs are values, assign a whole new one instead`.

## Examples

```js
const t = CATransform3D.rotation(Math.PI / 2, 1, 0, 0);
console.log(t.m32);
```

**Result**: logs `-1`.

## Corresponding iOS API

The C struct field `CATransform3D.m32`.
