# `CATransform3D`: `m11` property

The **`m11`** property is the number in the first row, first column of the matrix. When there is only scaling, it is the multiple in the x direction.

## Value

A number; a ratio with no unit. Its position in the matrix:

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

When a point is transformed, the original x is multiplied by it and added to the new x'. See [how the matrix acts on a point](../ca-transform-3d.md).

- Read-only. Assigning to it throws `TypeError: m11 is read-only: structs are values, assign a whole new one instead`.

## Examples

```js
const t = CATransform3D.scale(2, 3, 4);
console.log(t.m11);
```

**Result**: logs `2`.

## Corresponding iOS API

The C struct field `CATransform3D.m11`.
