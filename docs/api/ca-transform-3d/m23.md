# `CATransform3D`：`m23` 属性

**`m23`** 属性是矩阵第二行第三列的数。只绕 x 轴旋转时它是转角的正弦。

## 值

数，比例，没有单位。在矩阵里的位置：

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

变换一个点时，原来的 y 乘以它，加进新的 z'。见[矩阵怎么作用在点上](../ca-transform-3d.md)。

- 只读。给它赋值抛 `TypeError: m23 is read-only: structs are values, assign a whole new one instead`。

## 示例

```js
const t = CATransform3D.rotation(Math.PI / 2, 1, 0, 0);
console.log(t.m23);
```

**结果**：输出 `1`。

## 对应的 iOS API

C 结构体的字段 `CATransform3D.m23`。
