# `CATransform3D`: `m42` property

The **`m42`** property is the number in the fourth row, second column of the matrix. It is the translation in the y direction.

## Value

A number, in [pt](../units.md). Its position in the matrix:

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

When a point is transformed, it is added directly to the new y'. See [how the matrix acts on a point](../ca-transform-3d.md).

- Read-only. Assigning to it throws `TypeError: m42 is read-only: structs are values, assign a whole new one instead`.

## Examples

```js
const t = CATransform3D.translation(10, 20, 30);
console.log(t.m42);
```

**Result**: logs `20`.

## Corresponding iOS API

The C struct field `CATransform3D.m42`.
