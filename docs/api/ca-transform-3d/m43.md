# `CATransform3D`：`m43` 属性

**`m43`** 属性是矩阵第四行第三列的数。它是 z 方向的平移量。

## 值

数，单位 [pt](../units.md)。在矩阵里的位置：

```
| m11 m12 m13 m14 |
| m21 m22 m23 m24 |
| m31 m32 m33 m34 |
| m41 m42 m43 m44 |
```

变换一个点时，它直接加进新的 z'。见[矩阵怎么作用在点上](../ca-transform-3d.md)。

- 只读。给它赋值抛 `TypeError: m43 is read-only: structs are values, assign a whole new one instead`。

## 示例

```js
const t = CATransform3D.translation(10, 20, 30);
console.log(t.m43);
```

**结果**：输出 `30`。

## 对应的 iOS API

C 结构体的字段 `CATransform3D.m43`。
